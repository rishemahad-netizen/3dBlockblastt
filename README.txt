BLOCK BLAST 3D - WEBSITE (flat folder, no sub folders)
=======================================================
Upload EVERYTHING in this folder to the root of your GitHub repo:

  index.html        the website
  play.html         the game itself (the site embeds it and has a "Play in browser" button)
  shot-*.webp       game screenshots used on the site
  .nojekyll         tells GitHub Pages to serve the files as they are
  BlockBlast3D.apk  the APK (already included, the Download buttons point to it)

The APK must be named exactly BlockBlast3D.apk (same name build_apk.bat creates).
Until it is uploaded, the download buttons show "APK coming soon" on the live site.

GitHub Pages: repo > Settings > Pages > Deploy from a branch > main / (root).
Your site will be at https://YOURNAME.github.io/REPONAME/
